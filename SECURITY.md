# Security Policy

## Supported Versions

Security fixes are prioritized for the default branch and the latest release tag.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

1. Email: security@ngohomesuite.org
2. Include: impact, reproduction steps, affected versions, and any proof-of-concept.
3. Optional: include suggested remediation.

We will acknowledge receipt within 2 business days and provide a remediation status update within 7 business days.

## Disclosure Policy

- We follow coordinated disclosure.
- We may request a temporary embargo until a fix is available.
- After remediation, we publish release notes with security impact details.

## Secrets and Credentials

- Do not commit real credentials to source control.
- Rotate any exposed credentials immediately.
- Use environment variables or secret files for deployment.
