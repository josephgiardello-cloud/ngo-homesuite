# Demo Recording Guide

Use this script to record a short product demo (3-5 minutes):

1. Login as admin.
2. Show dashboard KPIs and key navigation.
3. Open Donors, filter, and open a donor profile.
4. Record a donation and show receipt generation.
5. Open Reports and export compliance evidence.
6. Open Copilot and show pending approval queue with action approval.

Suggested output filename:
- ngo-homesuite-beta-demo.mp4
